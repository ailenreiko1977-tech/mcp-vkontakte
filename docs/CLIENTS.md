# Подключение приложений

Общий адрес после развёртывания: `https://<твой-домен>/mcp`. HTTPS, Streamable HTTP и OAuth отделены от VK API. Keycloak авторизует пользователя нашего сервера; VK-токен добавляется отдельно в кабинет этого пользователя.

На 22 октября 2026 изучена официальная документация. Реальное подключение во всех перечисленных приложениях ещё не выполнялось. Цена подписки сама по себе не устанавливает точный тариф и доступность функции в аккаунте. Пользователь сообщил о базовых платных тарифах около $20 и использовании браузера, Windows и телефона; названия тарифов и видимые настройки аккаунтов не проверялись.

| Клиент | Что предусмотрено | Что остаётся проверить |
|---|---|---|
| Codex локально на Windows | Streamable HTTP и OAuth; единый HTTPS endpoint | Вход Keycloak и выполнение инструментов в установленной версии |
| ChatGPT в браузере | Подключение собственного удалённого MCP по поддерживаемому потоку OAuth | Доступность добавления сервера в конкретном аккаунте, callback и UI подтверждений |
| Приложение ChatGPT на Windows | Сервер использует стандартный транспорт; документация описывает настройки MCP для desktop | Какая именно версия приложения установлена и какие функции включены |
| ChatGPT на телефоне | Предполагается использование серверного подключения аккаунта там, где это поддерживает клиент | Доступность собственного MCP и записи в мобильном клиенте; гарантия пока не дана |
| Claude в браузере и Claude Desktop | Пользовательский remote connector, OAuth и публичный HTTPS | Вход через выбранный Keycloak-клиент и поведение инструментов |
| Claude на телефоне | Документация описывает remote connectors, соединение идёт из облака Anthropic | Добавление/включение конкретного сервера и фактические возможности приложения |

Облачные клиенты соединяются с публичным сервером через интернет. Локальный stdio-процесс на Windows не заменяет HTTPS-сервер для облачных приложений. Секреты хостинга 4VPS не передаются ни MCP-клиентам, ни пользователям VK-сервера.

## Codex

После настройки redirect URI клиента `vk-mcp-codex` можно добавить сервер через настройки MCP в приложении либо CLI:

```sh
codex mcp add vkontakte --url https://<домен>/mcp --oauth-client-id vk-mcp-codex
codex mcp login vkontakte
```

Проверять не только запись в списке, но OAuth, вызов `list_connections` и отдельный реальный read-only запрос VK. Браузерное подтверждение изменений специально одинаково для разных клиентов.

## ChatGPT и Claude

Добавить собственный MCP/connector в настройках соответствующего аккаунта, указать HTTPS URL. Если интерфейс разрешает ручной client ID, использовать предварительно созданный клиент Keycloak и точный разрешённый callback. Если он требует CIMD или DCR, настроить совместимость отдельно; шаблон не включает открытую автоматическую регистрацию OAuth-клиентов.

Для внесения изменений модель получает ссылку на защищённую форму. Даже если приложение автоматически разрешает вызовы инструментов, это не выполняет ожидающую запись VK. Подтверждение в нашем кабинете требуется отдельно. На телефоне ссылка открывается в браузере.

Наличие публичного GitHub-репозитория не размещает приложение автоматически в каталогах ChatGPT или Claude. Публикация в каталогах требует отдельных процедур и не включена в текущую настройку.
