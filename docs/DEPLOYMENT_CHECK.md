# Проверка развёртывания 22 октября 2026

Развёрнута инфраструктура прототипа 0.1.0: Ubuntu 26.04 LTS, Docker Engine 29.9.2, Docker Compose 5.6.1. Доступ к VPS выполнен через SSH. Для последующей работы создан отдельный SSH-ключ; его приватная часть хранится локально зашифрованной Windows DPAPI, вне Git. Пароль VPS в файл не сохранялся.

## Подтверждено

- Образы приложения собраны на VPS, Caddy, Keycloak и PostgreSQL запущены. Проверенные образы закреплены по digest в репозитории.
- Получен HTTPS-сертификат, `/health` возвращает 200. Проверка выполнена как с VPS, так и с Windows через внешний адрес.
- OIDC discovery и MCP protected resource metadata доступны по HTTPS и содержат согласованные issuer и resource.
- Вход в кабинет проверен на временном пользователе через настоящий OIDC authorization code с PKCE.
- Отдельно выполнен реальный OAuth authorization code с S256 для временного MCP-клиента, затем MCP initialize, tools/list и вызов list_connections. Получено 8 инструментов.
- Запрос к MCP без токена возвращает 401.
- Проверка обнаружила отсутствие `sub` в токенах первоначального realm. В Keycloak добавлен стандартный `oidc-sub-mapper`; строгие проверки подписи, аудитории и принадлежности пользователя не ослаблялись. Исправление добавлено в шаблон и тесты.
- Временные тестовые пользователи и OAuth-клиенты удалены после проверки.
- Внешний `/auth/admin/` возвращает 404; порты приложения, Keycloak и PostgreSQL наружу не публикуются. Ежедневный таймер очистки установлен и прошёл разовый запуск.
- Для владельца подготовлена отдельная учётная запись с временным паролем и обязательной сменой при первом входе. Пароль в GitHub и журналы проверки не выводился.

Начальное потребление памяти контейнерами было около 700 МБ суммарно, доступная память ОС около 2,6 ГБ. Это наблюдение в простое, не нагрузочный тест и не гарантия вместимости при публичной эксплуатации.

## Ещё требуется

Вход владельца и смена временного пароля; добавление VK-токенов через HTTPS-кабинет; отдельная проверка доступных методов для этих токенов; настройка redirect URI и реальный вход в каждом выбранном приложении. Публичная регистрация пока закрыта. SMTP, восстановление резервной копии, политика оператора, нагрузка и актуальные ограничения VK для анализа сторонних сообществ остаются отдельными задачами.

Успешная инфраструктурная проверка не утверждает работоспособность всех 434 методов VK и не подтверждает все мобильные и настольные клиенты.
